# Price Calculator

This small Project is the Pi Orchestrator first-run example. It begins with a tested integer-cents subtotal function and a ready-to-approve Plan for adding percentage discounts.

The Orchestrator creates this directory as a standalone Git repository. Configure `.pi/orchestrator.local.yaml`, then follow the root Pi Orchestrator README from `orchestrator doctor` onward.

The baseline test is:

```sh
node --test
```
